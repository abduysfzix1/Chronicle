# CHRONICLES — History Comes Alive

A cinematic historical museum homepage built with React, TypeScript, Vite, Framer Motion and Lucide icons.

## Requirements
- Node.js 20.19+ or 22.12+
- VS Code (recommended)

## Run locally on Windows
1. Extract this ZIP.
2. Open the `chronicles-website` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm.cmd install
npm.cmd run dev
```

5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Production build
```bash
npm.cmd run build
```
The generated website files will be in `dist`.

## Current homepage features
- Cinematic dark-and-antique-gold visual identity
- Responsive layout
- English / Urdu language toggle
- Animated hero content
- CSS-built 3D-inspired museum architecture
- Historical collection cards
- Archive feature section

## Important notes
This is the first homepage stage. It does not yet include a real Three.js scene, user accounts, database, magazine article pages, working quizzes, or a notes system. The historical collection card imagery currently uses remote Unsplash image URLs. Replace or verify images and historical content before public release.
